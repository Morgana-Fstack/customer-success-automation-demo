## Demonstração pública

Esta é a versão pública e isolada do Customer Success Automation Hub. Ela permite
explorar uma operação fictícia de Customer Success sem autenticação, banco de
dados ou upload de arquivos.

### Funcionalidades

- visão geral das prioridades do dia;
- carteira de clientes com filtros;
- página de clientes com cadastro e edição;
- análises de saúde, risco e churn;
- dados fictícios atualizados de acordo com a data;
- restauração da carteira original;
- alterações mantidas apenas na sessão de cada visitante.

## Segurança da demonstração

Este repositório não contém o aplicativo completo, integração com Supabase,
autenticação, credenciais, dados reais ou regras privadas do produto. Todos os
clientes e cenários são sintéticos.

## Executar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Testes

```bash
pip install -r requirements-dev.txt
```
